# Текущее состояние Shopping Sorter

На 2026-10-02. Версия в manifest.json: 20.7.
Результат изменений и их причины — в [памятке](refactoring-notes.md).

## Что проверено

- npm run check: ESLint без ошибок и предупреждений, 31 тест проходит.
- Тесты проверяют фильтрацию, сортировку тестовых товаров, открытие/закрытие
  панели, обработчики, диагностику селекторов и правила линтера.
- Проверены синтаксис скриптов, JSON и наличие файлов из manifest.

DOM и Chrome API в тестах имитируются. Реальный Chrome после рефакторинга
и исправлений ещё не проверен.

## Что осталось проверить

- «Открыть товары» на страницах без content script (новая вкладка, chrome://,
  магазин расширений): popup открывает saved-products.html — ту же панель на
  странице расширения. Покрыто тестом на состав скриптов; в реальном Chrome не проверено.

- Ozon: до исправлений часть карточек не распознавалась с причиной «нет цены»,
  кнопки сортировки не меняли порядок. Причины не установлены; исправление orig
  не подтверждает устранение этих проблем.
- ggsel: пользователь не увидел товаров; стандартной конфигурации ggsel нет.
- «Поиск на сайтах» (multi-search): логика адресов покрыта тестами, страница
  прогнана в Chromium с имитацией chrome API. В реальном расширении не проверены;
  встроенные шаблоны адресов поиска магазинов не сверялись с живыми сайтами.
- Плашка «№ в выдаче»: проверена в Chromium на тестовой странице с подгрузкой карточек
  (номера по порядку появления, остаются прежними после сортировки). На реальных магазинах
  не проверена. Нумерация идёт по порядку первого появления с начала загрузки страницы:
  после перехода на следующую страницу выдачи с перезагрузкой счёт начинается заново.
- Оформление, виртуализация, сетевые изображения и восстановление экспортов
  после рефакторинга не проверены.

Селекторы зависят от разметки магазина. Наличие домена в sites.json
не означает, что распознавание на нём сейчас работает.
Экспорт настроек и экспорт товаров — разные файлы; настройки не включают
все предпочтения интерфейса, а в товарах могут отсутствовать изображения.

## Как проверить в Chrome

Перезагрузите расширение и страницу по [README](../README.md).
Подождите около 10 секунд, проверьте Console, распознавание названий/цен,
поиск и сортировку. Затем проверьте сохранение и повторное открытие панели.
Восстановление товаров и настроек проверяйте в отдельном тестовом профиле.

После проверки запишите здесь дату, URL, результат и текст ошибки,
если она возникла. Сохраняйте актуальный статус, без истории промежуточных проходов.
