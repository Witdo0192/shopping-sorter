Как это работает: Расширение ищет карточки товаров по CSS-селекторам. Если сайт обновил дизайн — селектор перестаёт работать. Здесь можно исправить это без обновления расширения. Можно добавить несколько вариантов — расширение попробует каждый по очереди.
Имя сайта можно задать отдельно от внутреннего ключа. Поиск ниже работает по имени, домену и ключу, а выбранный способ сортировки списка запоминается.
Как это работает: Расширение ищет в названии товара единицы измерения и считает цену за базовую единицу. Например, «кг» → множитель 1000 при базе «г», так что 100₽/кг = 0.1₽/г. Можно добавить новые категории, единицы или изменить множители.
Порядок категорий: перетаскивайте блоки за ручку ⋮⋮ — это меняет только значения priority в JSON, сами блоки в файле не переезжают. При вводе уже занятого приоритета категория встанет перед существующей, а её и последующие приоритеты сдвинутся на +1.
Знаков после запятой — настройка только отображения (бейдж, фильтр, сортировка, переключение единицы). Округляется то, что показывается пользователю; сам расчёт, сравнение цены/ед. и фильтрация всегда используют точное значение. Для штучных величин удобно ставить 0, для дробных — 2–4.
🧪 Проверить на примере — вставьте название товара (и, по желанию, цену), чтобы увидеть прямо сейчас, что распознает парсер по текущим (в т.ч. ещё не сохранённым) настройкам единиц.
Виртуализация карточек
При большом количестве товаров расширение не создаёт все карточки одновременно, а держит в DOM только карточки около видимой области. Это особенно полезно для сайтов, которые сами держат сотни товаров на странице.
